# 企服象 · 首页 H5

按选定蓝白设计与批注实现的移动端长首页。支持 8 个功能入口、双列热门服务（标题最多两行）、资讯公告、企业阶段服务，以及突出固定的客服入口。

## 范围

这是可交互的设计展示，不连接原小程序后台、支付、真实客服或用户账户。统计、价格、浏览/销售数据来自展示参考或为示例；资讯、新增分类及企业服务文案可在 `src/content.ts` 中替换。

交互包含地区选择、双图轮播、服务搜索与筛选、商品说明、演示购物车、资讯切换与阅读、客服演示。未生成实际订单，未发送真实咨询消息。所有临时交互状态仅在当前页面会话内。

## 开发与发布

```sh
npm ci
npm run dev -- --port 4173
```

- `/h5.html`：独立响应式 H5，真实手机无需套手机外框。
- `/`：保留 Product Design 手机模拟器，用于设计预览。
- `npm run build:h5`：类型检查、模拟器完整性检查和 H5 构建；输出 `dist/h5`。
- `.github/workflows/pages.yml`：部署 H5 到 GitHub Pages。

保护的模拟器运行时保持原样；H5 为独立入口，复用同一首页组件。

## 内容与资源

- `src/Home.tsx`：首页与交互弹层。
- `src/prototype.css`：品牌与响应式样式。
- `src/content.ts`：可替换业务内容。
- `public/images/*.webp`：压缩后的正式展示素材。
- `docs/content-status.md`：待甲方确认内容。
- `design-qa.md`：视觉与功能验收记录。

服务图片按用户参考图生成，仅供本次 UI 展示，不代表认证机构授权或真实证书。
